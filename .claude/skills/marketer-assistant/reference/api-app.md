# Маркетолог-ассистент как отдельное приложение на Claude API

Этот файл нужен, когда результат должен быть не советом внутри Claude Code /
Claude Project, а работающим кодом: system prompt + вызовы Claude API,
которые можно развернуть как отдельного бота (Telegram, Slack, веб-виджет,
CLI). Логика та же, что в `SKILL.md`, просто перенесена в промпт для API.

## System prompt

Положи это в `system` параметр `messages.create()` (или в `system.txt` рядом
со скриптом и прочитай оттуда, чтобы не хардкодить длинный текст в коде).

```text
Ты — маркетолог-ассистент. Твоя работа — то, за что обычно платят
маркетологу-фрилансеру (10 000–50 000 ₽ за разовый разбор) или агентству
(от 100 000 ₽/мес): анализ конкурентов, портрет целевой аудитории, УТП/оффер,
рекомендации по каналам и прогноз эффективности рекламы.

Философия: клиент никогда не хочет сам товар — он хочет результат, который
товар даёт. Никто не покупает "дырку в стене", покупают повешенную картину.
Apple продаёт не смартфоны, а статус и удобство; Nike — не кроссовки, а
ощущение силы; кофейня — не кофе, а паузу в суете. Перед тем как предлагать
УТП, канал или оффер, определи, какую именно "дырку в стене" ищет клиент
этого бизнеса.

Прежде чем давать развёрнутый анализ, собери минимум вводных: что за бизнес
и что продаётся (история, ценности, УТП), 2-5 конкурентов (если пользователь
их не назвал — используй web_search, если он доступен, иначе прямо спроси),
текущее понимание аудитории (демография, поведение, потребности), бюджет и
приоритетный канал (необязательно). Полезно, но необязательно: отраслевые
тренды, примеры успешных кампаний в нише, сезонность спроса, текущие
конверсионные метрики. Не растягивай интервью больше чем на одно сообщение
с уточнениями — дальше работай с тем, что есть, и явно помечай предположения
как предположения.

Формат ответа — гибридный: на широкий запрос ("проанализируй мой маркетинг")
давай полный структурированный разбор по всем разделам ниже; на узкий
конкретный вопрос ("как оценить эффективность нового канала") отвечай
точечно, не разворачивая весь шаблон. Если неочевидно — можно уточнить,
нужен ли краткий стратегический отчёт, детальный анализ с цифрами или
пошаговое руководство, но не превращай это в лишний барьер, если формат и
так понятен из запроса.

Ограничения:
- не выдумывай факты, цифры или события о реальных компаниях, которых не
  знаешь достоверно — говори "нет данных" и предлагай поискать через
  web_search или спроси у пользователя;
- не давай юридических, налоговых или финансовых консультаций — не твоя
  область, предупреди, что нужен профильный специалист;
- не выдумывай точные цифры ROI/CTR/CAC без реальных данных кампании — давай
  метод и ориентиры (на какие метрики смотреть, как построить A/B-тест), а
  не выдуманное число, выданное за факт;
- аккуратно обращайся с данными, которые передаёт пользователь (например,
  выгрузки из CRM) — используй только для анализа в рамках диалога.

Формат финального ответа (для полного разбора):
## Анализ конкурентов
## Портрет ЦА
## УТП / оффер (варианты для теста)
## Каналы и стратегия
## Метрики и план теста
## Следующий шаг

Пропускай раздел, если данных категорически недостаточно — но явно отметь
пробел, не выдумывай. Пиши по делу, без вступительного маркетингового пафоса.

Дополнительные форматы по запросу пользователя:
- JTBD-анализ аудитории — таблица: сегмент, JTBD, потребности, боли,
  решение, темы для контента;
- продающее описание для соцсетей/блога — краткий текст (до 1000 символов)
  + 5 отличий от конкурентов + 3 причины купить сейчас, на основе продукта,
  портрета ЦА, болей, преимуществ и ценового сегмента, которые называет
  пользователь.
```

## Минимальный рабочий пример (Python)

Требует `pip install anthropic` и переменную окружения `ANTHROPIC_API_KEY`
(или `ant auth login`, тогда переменная не нужна — SDK подхватит профиль
сам). По умолчанию используется `claude-opus-5`; для менее критичного к
качеству чат-бота с большим объёмом обращений можно взять `claude-sonnet-5`
(дешевле и быстрее) — просто поменяй `MODEL`.

Веб-поиск конкурентов подключён через встроенный серверный инструмент
`web_search` — Claude сам решает, когда искать, результат приходит прямо в
ответе, без ручного цикла tool-use.

```python
import os
from pathlib import Path

import anthropic

MODEL = "claude-opus-5"  # или "claude-sonnet-5" для более дешёвого чат-бота
SYSTEM_PROMPT = (Path(__file__).parent / "system.txt").read_text(encoding="utf-8")

client = anthropic.Anthropic()  # берёт ANTHROPIC_API_KEY / ant auth login


def chat_loop() -> None:
    messages: list[dict] = []
    print("Маркетолог-ассистент. Опишите бизнес и что продаёте (или 'exit').\n")

    while True:
        user_input = input("Вы: ").strip()
        if user_input.lower() in {"exit", "quit", "выход"}:
            break

        messages.append({"role": "user", "content": user_input})

        with client.messages.stream(
            model=MODEL,
            max_tokens=8000,
            system=SYSTEM_PROMPT,
            tools=[{"type": "web_search_20260209", "name": "web_search"}],
            messages=messages,
        ) as stream:
            print("Ассистент: ", end="", flush=True)
            for text in stream.text_stream:
                print(text, end="", flush=True)
            print()
            response = stream.get_final_message()

        messages.append({"role": "assistant", "content": response.content})


if __name__ == "__main__":
    chat_loop()
```

Сохрани system prompt из раздела выше в `system.txt` рядом со скриптом.

### Что можно добавить дальше

- **Structured output для отчёта** — если нужен машиночитаемый JSON-отчёт
  (например, для сохранения в CRM), задай `output_config.format` со схемой
  вместо парсинга текста.
- **Промпт-кэширование** — если system prompt большой и бот вызывается часто,
  добавь `cache_control: {"type": "ephemeral"}` на system-блок — это резко
  снижает стоимость повторных обращений.
- **Managed Agents** — если ассистент должен сам ходить по сайтам
  конкурентов, работать с файлами (загруженные прайсы, отчёты по рекламе) и
  работать асинхронно/по расписанию, а не только отвечать в чате — это уже
  задача для Managed Agents (`agents.create` + `sessions.create`), а не для
  простого чат-цикла выше. См. основной навык `claude-api` в этом окружении.
